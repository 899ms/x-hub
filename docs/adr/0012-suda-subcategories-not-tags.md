# 0012-速达采用大类下单归属的小类体系（非多选标签）

> **状态：已实施**（决策于「速达功能优化」设计讨论，2026-09-24；术语见 `CONTEXT.md` 的「速达」一节。2026-09-25 实施并按建议口径处理「未决」项，见文末修订节。）

## 问题

速达资源的组织只有 `resources.kind`（应用 / 网页 / 文件）一层；二级分类只有「文件」在用——7 个写死的 `category` 值，应用 / 网页一律 null。需求要「大类下的小类区分（或叫标签）」，需要定：模型（层级小类 vs 扁平标签）、命名域、缺省归属、存量 category 去留、管理入口。

## 决策

1. **模型 = 小类**：大类下的二级归属，每条资源恰好归属一个小类（单归属），**不是**多选标签（标签语义归 ADR 0010 那套，资源不复用）。
2. **库 = 各大类一套**：允许同名不同义；「应用」「网页」初始为空、按需新建；「文件」**并入现有 7 个内置 category**（文件夹 / 文档 / 图片 / 视频 / 音频 / 压缩包 / 其他）作为初始小类，**不做 category 与小类双轨**。
3. **缺省自动补默认**：新建 / 拖拽导入 / 扫描装应用未指定小类，自动归入该大类的「默认」小类，用户事后可改。
4. **存量不回填**：现有条目没有分类的保持空着（「未归类」状态，与默认小类区分）。
5. **管理入口 = 设置页单开「小类」管理区**：按大类分组列出，行内改名、拖拽排序；删除小类时其条目归入默认小类。速达页只放小类选择器，不做内联管理。
6. **命名 = 「小类」**（连同「大类」「默认小类」进 `CONTEXT.md` 术语表），与 ADR 0010 的标签、设置页「分类」锚点三分开。

## 依据

- 层级小类 vs 扁平标签：原话「大类下的小类区分」落在层级归属；标签是多选横切，两套语义混用会在 UI 与查询上互相打架（ADR 0010 已为笔记 / 待办标签隔离过一次，先例沿用）。
- 各大类一套 vs 全局池：同名不同义是真实需求（「文档」在文件与应用下不是一回事）；全局池会让筛选语义漂移，也与单归属模型不自洽。
- 并入 7 内置 vs 双轨：那 7 个值本来就是文件的二级分类，语义零变化、数据零搬迁；双轨要维护两套映射，白添复杂度。
- 管理进设置页：速达是浏览路径，行内编辑会打断浏览；设置页的分区管理（布局编辑器、快捷键）是既有模式。

## 后果

- `resources.category` 从「文件专属 7 值枚举」升级为「所属大类小类库中的一个小类」；7 值直接当文件大类的初始小类，应用 / 网页的 null 保持 null。
- 需要小类定义存储（大类 / 名称 / 排序 / 是否默认）；删除小类时条目批量改挂默认小类，单事务完成。
- 全局搜索、概览卡等按 category 聚合的展示要换口径（「未归类」与「默认」分开显示）。

## 未决（下一轮）

- 默认小类的性质：可否改名 / 删除 / 隐藏；文件大类的默认是否直接以「其他」承接。
- 图标选择器的交互细化；双载体下的打开落点与布局（见 ADR 0011 修订）。

## 修订（2026-09-25，实施记录 + 未决项按建议口径处理）

- **实现形态**：`resource_subcategories` 表（`UNIQUE(kind, name)`，各大类一套同名不同义）+ 建表种子（文件 7 个内置 category 并入为初始小类，`INSERT OR IGNORE` 幂等）；`resources.category` 语义升级为「所属大类小类库中的一个小类名」，改名/删除在 repo 层单事务级联资源条目。命令 6 个（list/create/rename/delete/reorder/set_default）+ `set_suda_web_open_mode`。前端：速达页小类筛选通栏（应用/网页/文件通用 + 未归类 + 默认星标）、SudaFormDialog 小类选择（全大类，编辑含「未归类」）、设置 → 功能 → 速达「小类管理」（行内改名 / 指针拖拽排序 / 星标设默认 / 两段式删除确认）。
- **默认小类性质（原未决）**：可改名、可删除（删默认时排序最前的剩余小类自动晋升为默认，条目随之改挂）；**未做隐藏**。文件大类默认暂由「其他」承接。
- **自动归默认**：新建（含拖拽导入/扫描装应用/扩展桥 `data.resources.create`）未指定小类 → 自动归入该大类默认小类，该大类还没有小类则保持 NULL（未归类）；编辑时显式置空 = 未归类（存量不回填口径不变）。
- **未做、待确认**：小类图标选择器（数据结构未含图标字段，后加需迁移）；「未归类」筛选恒显示（即使该大类 0 条未归类，避免列表忽隐忽现）。
